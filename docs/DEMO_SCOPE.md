# MVP Demo 范围说明

本项目是永久保持演示定位的纯前端原型，用于产品交流、客户展示和页面交互评审。它不处理真实知识产权申请，也不提供真实业务系统的数据服务。

## 可体验与边界

| 体验区域 | 演示内容 | 边界 |
| --- | --- | --- |
| 登录与创建团队 | 预填账号、创建虚构账号与组织 | 不验证身份、邮箱或账号归属 |
| 工作台 | 示例统计、任务进展、活动记录 | 仅基于当前浏览器中的演示数据 |
| 客户与案件 | 虚构客户、案件列表、详情和关联信息 | 不连接官方数据库，不承接真实申请 |
| 材料目录 | 示例文件名称与状态 | 无真实文件、上传、下载或解析 |
| 任务 | 完成及重新打开任务 | 状态仅保存在本机浏览器，无通知服务或期限计算 |
| 成员与角色 | 管理员、经办人、只读成员交互差异 | 前端模拟，无安全授权保障 |
| 多组织 | 切换不同组织的样例 | 浏览器内分组展示，无服务端租户隔离 |
| 重置 | 恢复初始演示场景 | 会删除本应用的本地演示修改 |

## 存储行为

- 演示业务数据保存在网站当前来源下的 `localStorage`；刷新页面可以保留修改。
- 登录状态保存在 `sessionStorage`；关闭对应浏览器会话后需要重新进入。
- 不同设备、浏览器和站点来源之间没有同步，也没有服务器备份。
- 演示账号的公开密码是 `Demo123456!`。新建演示账号的密码只检查输入长度，不被保存，也不用于真实认证。
- 用户可自行编辑浏览器存储，因此角色与组织限制不能保护真实敏感信息。
- 重置入口位于「组织设置 → 演示数据」。确认后恢复样例并清除当前演示登录状态。

## 不在范围内

不提供真实身份认证、多用户协作服务、后端 API、数据库、文件存储、邮件或消息发送、AI 调用、RAG、Agent、官方系统对接、法律判断或真实案件交付能力。

代码中的接口形状与业务名称用于组织前端演示，不能据此视为已经接入真实服务。所有样例均为虚构；演示者应使用虚构资料，不输入真实个人信息、客户资料、专利技术内容或常用密码。

## 演示反馈建议

评审重点可放在导航是否清晰、页面信息是否易读、案件与任务关系是否直观、角色交互是否容易理解。构建和演示验收只证明对应页面或交互可运行，不代表生产可用、安全认证有效或业务合规。

项目目标弹窗使用浏览器本地时间记录一小时冷却，保持显示，直到用户点击遮罩或关闭按钮；不依赖服务器。
