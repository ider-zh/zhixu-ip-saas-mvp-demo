# 知序 · 知识产权协作平台 — MVP DEMO

> **纯前端交互演示，非生产系统。** 登录、角色、组织及业务流程均为浏览器内模拟，不验证真实身份，不是多用户服务。请只使用虚构信息，不要输入真实客户、专利资料或常用密码。

知序展示一个知识产权团队工作空间的产品构想：将客户、案件、任务和成员放在统一界面中，让团队能够快速了解工作全貌、查看案件细节并体验任务协作。

本项目用于客户演示、交互评审与产品方向讨论，并将始终保持 **Demo 定位**，不接入真实申报业务。

## 三分钟体验

1. 打开演示网站，先了解「项目开发目标」，再使用页面预填账号进入工作台。
2. 查看客户、案件与任务概览，打开案件查看示例详情和材料目录。
3. 在任务页完成一项任务，观察状态及工作台变化；刷新页面后，修改仍保存在当前浏览器。
4. 到团队成员页创建虚构成员，调整角色，体验不同角色下的交互限制。
5. 创建或切换演示组织，比较各自的示例数据空间。

| 演示账号 | 演示密码 |
| --- | --- |
| `demo@zhixu.local` | `Demo123456!` |

也可以选择「创建团队」：表单会预填虚构账号信息，新账号和新组织会生成一组独立样例，方便完整演示。

首次进入会显示项目目标弹窗，5 秒后自动关闭，也可点击弹窗外空白区域提前关闭。同一浏览器有 1 小时冷却时间，冷却结束后再次打开页面会重新显示。

## 已展示的能力

- **工作台**：客户、案件、任务、完成数量与近期活动。
- **案件与客户**：示例列表、案件详情、关联任务及材料目录。
- **任务交互**：完成任务、重新打开，状态保存在当前浏览器。
- **团队与组织**：模拟新增成员、角色调整、最后一位管理员保护和组织切换。
- **演示重置**：恢复初始样例，方便下一次展示。

所有客户名称、联系人、案件、材料及任务都为虚构样例，不对应真实申请。材料仅展示记录，不包含可下载文件；不提供真实上传、解析、AI 生成、官方申报或知识产权专业判断。

## 数据与权限说明

数据保存于当前网站、当前浏览器的 `localStorage`，登录状态保存在 `sessionStorage`。其他设备、浏览器或不同网址不会同步；清理浏览器存储会移除本地修改。

角色限制仅用于展示页面交互，浏览器中的数据可被使用者修改，**不构成安全权限控制或身份认证**。演示输入的密码不会保存；默认演示账号使用上表中的公开密码，新建的演示账号接受任意 10–128 位演示密码。

在「组织设置 → 演示数据 → 重置演示数据」中确认重置，将删除本应用保存的演示账号、组织、任务和登录状态，恢复初始样例。请勿把浏览器中的演示内容作为业务记录保存。

完整展示范围见 [Demo 范围说明](docs/DEMO_SCOPE.md)。

## 本地体验与部署

本项目使用 React、TypeScript、Ant Design 和 Vite，仅需静态网站托管。无需后端、SQLite、Docker、Cloudflare Worker、D1 或 R2，也无需配置业务环境变量、API Token 或部署密钥。

```bash
# Node.js 22
npm ci
npm run dev
```

生产静态资源通过 `npm run build` 生成至 `dist/`。你可以自行使用 Cloudflare Pages 连接 [GitHub 仓库](https://github.com/ider-zh/zhixu-ip-saas-mvp-demo)，或上传已构建的静态资源。

具体参数与操作见 [部署说明](docs/DEPLOYMENT.md)。CI 仅检查构建并保留静态产物，不自动发布网站。
